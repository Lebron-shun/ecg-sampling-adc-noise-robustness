Project Overview

从虚拟采集链路到参数推荐的完整ECG评估项目

页面围绕可穿戴心电监护中的采集参数选择展开，展示数据来源、虚拟前端、全因子实验、抗噪评估和最终配置推荐。

Scenario 可穿戴ECG长时监护

聚焦R峰、RR间期、心率趋势和HRV技术可用性，不外推临床诊断或形态学判读。

Design 采样率 × ADC位数

联合评估5种采样率和6种ADC有效位数，比较检测性能与数据率。

Pipeline 虚拟采集与数字处理

通过重采样、量化、XQRS检测和指标统计模拟不同采集配置。

Data MIT-BIH与NSTDB

覆盖48条MIT-BIH记录和12条噪声压力测试记录，保留可复现实验入口。

Metrics 性能、码率与鲁棒性

综合Clean F1、R峰时间误差、RR/HR误差、原始码率和不同SNR下的性能退化。

Result 360 Hz / 6 bit推荐配置

在保持R峰检测可靠性的同时，相比参考配置显著降低原始数据率。

Artifacts 代码、结果表与图表

提供复现实验脚本、参数配置、结果表、网页数据和9张实验图。

Open Source GitHub仓库与网页展示

仓库包含数据说明、配置文件、分析脚本和可交互展示页面。
